# Klávesové zkratky

Klávesy bez Ctrl nebo Alt nefungují, když píšeš do textového pole;
klávesy s Ctrl a Alt fungují všude. Lišta dole v okně ukazuje
klávesy obrazovky, na které jsi — kliknutím klávesu stiskneš.

## Všude

| Klávesa | |
|---|---|
| `d` | Přehled |
| `c` | Konverzace |
| `h` | Archiv (archivované konverzace) |
| `s` | Živé relace |
| `v` | Analytika |
| `n` | Nová konverzace |
| `?` | Tato nápověda |
| `Ctrl+P` | Nastavení (jazyk, motiv, Telegram, fronty, předvolby, záloha) |
| `Ctrl+Q` | Zavřít ccc (běží dál; `ccc` ho zase otevře) |
| `Esc` | Zpět / zavřít |

## Přehled

| Klávesa | |
|---|---|
| `Enter` | Otevřít detail fronty |
| `q` | Zavřít ccc (stejně jako Ctrl+Q) |

## Živé relace

| Klávesa | |
|---|---|
| `Enter` | Poslat vybrané relaci prompt |
| `r` | Znovu načíst seznam relací |
| `a` | Přidat prompt do fronty projektu |

## Konverzace

| Klávesa | |
|---|---|
| `Enter` | Otevřít Claude Code CLI konverzace (v seznamu) / odeslat zprávu (v poli) |
| `r` | Zablokovaná: znovu spustit selhaný úkol / pokračovat po pauze na limitu |
| `t` | Editor úkolů (fronta, plánování, pauza, automatické pokračování) |
| `p` | Schválit nástroj, na který Claude čeká |
| `x` | Archivovat (přesune do Archivu, h) |
| `Alt+0` | Přepnout mezi ccc a Claude Code (když je otevřený vedle ccc) |
| `Ctrl+]` | Zavřít Claude Code vedle ccc (běží dál; Enter v seznamu ho otevře) |
| `/` | Hledat ve všech konverzacích |
| `e` | Exportovat konverzaci jako Markdown |
| `Ctrl+J` | Nový řádek v poli pro zprávu (Shift+Enter, kde funguje) |
| `Alt+1` | Přednastavený prompt 1–9 (⏎ odešle, ✎ vloží do pole pro zprávu; nastavíš v Nastavení) |
| `Alt+2` | Přednastavený prompt 2 |
| `Alt+3` | Přednastavený prompt 3 |
| `Alt+4` | Přednastavený prompt 4 |
| `Alt+5` | Přednastavený prompt 5 |
| `Alt+6` | Přednastavený prompt 6 |
| `Alt+7` | Přednastavený prompt 7 |
| `Alt+8` | Přednastavený prompt 8 |
| `Alt+9` | Přednastavený prompt 9 |

## Archiv

| Klávesa | |
|---|---|
| `x` | Obnovit konverzaci |
| `Enter` | Obnovit ji a otevřít v Konverzacích |
| `Del` | Smazat konverzaci z ccc (nejdřív se zeptá; přepis Claude Code zůstane) |
| `/` | Hledat ve všech konverzacích |
| `e` | Exportovat konverzaci jako Markdown |

## Editor úkolů (t)

| Klávesa | |
|---|---|
| `a` | Přidat úkol |
| `e` | Upravit úkol (také Enter) |
| `Del` | Odebrat úkol |
| `Ctrl+↑` | Posunout nahoru |
| `Ctrl+↓` | Posunout dolů |
| `p` | Pozastavit / obnovit frontu |
| `o` | Zapnout / vypnout automatické pokračování |
| `Ctrl+S` | Uložit v editoru úkolu |

## Okno schválení (p)

| Klávesa | |
|---|---|
| `y` | Povolit |
| `a` | Vždy povolit tento nástroj v této konverzaci |
| `n` | Zamítnout |

## Analytika

| Klávesa | |
|---|---|
| `←` | Předchozí kalendářní měsíc |
| `→` | Další kalendářní měsíc |

## Detail fronty

| Klávesa | |
|---|---|
| `Enter` | Ukázat diff commitu z běhu |
| `a` | Přidat prompt (s předvyplněnou cestou této fronty) |
| `r` | Zablokovaná: znovu spustit selhaný úkol / pokračovat po pauze na limitu |

## Editor přednastaveného promptu (Nastavení → Přidat / Upravit)

| Klávesa | |
|---|---|
| `Ctrl+S` | Uložit |
| `Esc` | Zrušit |

## Nastavení (Ctrl+P)

| Klávesa | |
|---|---|
| `Ctrl+S` | Uložit |
| `Esc` | Zrušit (vrátí se i motiv) |
